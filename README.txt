Python 基礎入門｜39頁16:9 GitHub Pages 網站

請先將 ZIP 解壓縮，將 index.html、data.js、slides 資料夾（39張圖片）全部上傳至 GitHub 儲存庫的最上層。
進入 Settings → Pages → Build and deployment，Source 選 Deploy from a branch；Branch 選 main，資料夾選 /(root)，按 Save。
網址通常是 https://帳號.github.io/儲存庫名稱/

操作：左右方向鍵換頁、N 顯示/隱藏講稿、F 全螢幕、Esc 退出全螢幕。
講稿直接擷取自您這次上傳的 PowerPoint 備忘稿。網站無須安裝外掛。
